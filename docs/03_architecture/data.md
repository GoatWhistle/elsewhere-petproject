# Данные

## Источники

| Потребность | Источник | Режим |
|---|---|---|
| направления и объекты размещения | разовый сбор публичного каталога | локальная база |
| берег, дороги, POI, аэропорты и пешеходная сеть | OpenStreetMap через ограниченный импорт Overpass | PostGIS |
| независимая проверка расстояния до берега | ohsome count API | отдельная проверка, не request path |
| длительность трансфера | OpenRouteService | необязательный предварительный расчёт |
| климатические нормы и прогноз | Open-Meteo | нормы кэшируются, прогноз имеет свежесть |
| авиатарифы | Ignav | живой запрос, snapshot сохраняется |
| цена проживания на даты | собственная детерминированная модель | локальный расчёт |
| отзывы | источника нет | всегда `unavailable` с причиной |

`SUPPLY_MODE=fixture` использует захваченные ответы и небольшой стабильный набор. `SUPPLY_MODE=live` читает
собранный корпус и локальные признаки, а наружу обращается только за тем, что действительно должно быть свежим.

## Наблюдаемое и модельное

Наблюдаемыми считаются каталог, тарифы, географические расстояния и погода. Они несут `freshness`, а тариф ещё и
`as_of`.

Цена проживания на конкретные даты — единственная синтетическая денежная величина:

```text
наблюдаемый базовый уровень объекта × сезонный коэффициент × число ночей
```

Сезонность — гипотеза модели, а не наблюдение. Результат детерминирован, хранит ссылку на калибровку и везде
помечается `modeled`. При отсутствии наблюдаемой базы сумма остаётся отсутствующей с причиной.

Трансфер и локальная мобильность не подставляются выдуманными суммами: если защитимого источника стоимости нет,
компонент не включается в итог.

## Географические признаки

OSM импортируется один раз ограниченными bbox вокруг объектов корпуса. В PostGIS рассчитываются:

- расстояния до моря, центра, аэропорта и крупной дороги;
- класс ближайшей дороги;
- POI и рестораны в радиусе 500 м;
- плотность POI;
- длина пешеходной сети в радиусе 500 м;
- при наличии ORS — длительность автомобильного трансфера.

Ни OSM, ни ORS не вызываются при генерации Future. Отсутствующая береговая линия и неимпортированный слой —
разные состояния: первое является фактом, второе записывается в `unassessed`.

## Признаки для продукта

| Измерение | Признак |
|---|---|
| `sea_access` | расстояние до береговой линии |
| `walkability` | POI и пешеходная сеть рядом |
| `food_quality` | рестораны и кафе в 500 м |
| `quiet` | класс и расстояние до дороги; только косвенный показатель |
| `climate_warm` | климатические нормы на даты поездки |
| `crowds` | сезонность как косвенный показатель |
| `comfort` | рейтинг объекта |
| `transfer_simplicity` | расстояние или время пути от аэропорта |
| `total_budget` | арифметика наблюдаемого тарифа и модельного проживания |

Недоступный признак попадает в `unscored_dimensions` или `coverage`; нейтральное значение не подставляется.

## Владение таблицами

| Пакет | Таблицы |
|---|---|
| Supply | `destinations`, `properties`, `osm_features`, `property_geo_features`, `destination_climate_normals`, `flight_fare_snapshots`, `price_calibrations` |

Пакет не читает чужую таблицу напрямую. Через границу передаются value objects или JSON-значения, но не модели
ActiveRecord.

## Операционные ограничения

- Каталог собирается вежливым ограниченным проходом, не во время запроса и без обхода защиты от ботов.
- Основной OSM API предназначен для редактирования; проект использует Overpass для одноразового ограниченного
  извлечения и хранит результат локально.
- Бесплатный Open-Meteo предназначен для некоммерческого использования; коммерческий запуск требует пересмотра
  тарифа.
- Ключи ORS и Ignav хранятся только в `.env`.

Проверенные основания выбора источников собраны в [research_log.md](../02_research/research_log.md).
