# Принципы API

Сам контракт — [openapi.yaml](openapi.yaml). Этот документ про *почему*, чтобы следующий человек, расширяющий API,
тихо не отменил принятое решение.

---

## 1. Деньги — целое число в минорных единицах

`{ "amount_minor": 154000, "currency": "RUB" }`, никогда `1540.0`.

Цены складываются, вычитаются и показываются пользователю. Симулятор, весь вывод которого «−24 900 ₽, вот три
составляющих», не может использовать числа с плавающей точкой. Валюта — рубль согласно
[DEC-007](../00_project/decision_log.md).

## 2. Каждый компонент цены объявляет, как он может быть исполнен

`fulfilment: estimate | modeled`

- `estimate` — a real observed market price we cannot sell (flight fare from Ignav).
- `modeled` — generated by us from a defined basis (room rate, calibrated on observed price levels; transfer).

Через Elsewhere ничто не бронируется (DEC-017). Ровно одно число в продукте синтетическое — цена номера, — а
пользователь рассуждает об итоге как об одной цифре. Это самый крупный риск честности в продукте, поэтому
разделение принуждается схемой, а не оставляется на текст в интерфейсе.

## 3. Всё, что может быть медленным, — это задача

Генерация Future, симуляция и смягчение возвращают `202` и `Job`. Обращения к поставщикам, оценка и выбор
разнообразия не относятся ко времени ответа, и притворство обратным даёт таймауты ровно в тех условиях, которые
создаёт демонстрация.

В MVP — опрос. Server-sent events или Action Cable могут заменить транспорт позже, не меняя формы контракта:
ресурс задачи остаётся.

## 4. Futures неизменяемы и версионируются

Симуляция никогда не изменяет Future; она порождает новую версию с `parent_id`, `lineage_id` и `delta`.

Пользователи исследуют, двигаясь туда и обратно, поэтому отмена — не любезность. Неизменяемость к тому же делает
дельту вычисляемой по построению, а не по памяти о том, как было раньше.

## 5. Ничто важное не является голым числом

- `ExperienceMatch` требует `contributions` — схема не может выразить непрозрачную оценку.
- `RiskItem` требует хотя бы одного `Evidence` — схема не может выразить риск без доказательства.
- `unscored_dimensions` и `Forecast.coverage` существуют, чтобы недостающие данные назывались, а не оценивались
  молча как нейтральные.

Эти ограничения — продуктовый тезис, выраженный системой типов. Если бы схема позволяла срезать углы, реализация
срезала бы их под давлением сроков — ровно тогда, когда решается доверие к продукту.

## 6. Происхождение и уверенность путешествуют вместе с выведенными данными

Каждый `TravelDnaElement` несёт `provenance` (`stated` / `inferred` / `confirmed` / `default`) и `confidence`.
Каждый `RiskItem` несёт `claim_kind` (`verified_fact` / `derived_metric` / `model_inference`).

Пользователь обязан видеть, что система про него предположила, и уметь это поправить. `unmatched_intent`
существует, чтобы то, что таксономия не смогла представить, всплывало, а не выбрасывалось: молчаливое
выбрасывание намерения — ровно тот путь, которым Travel DNA вырождается в фильтры.

## 7. Побочных эффектов нет

Elsewhere не создаёт заказов и не берёт денег (DEC-017). Каждая запись в API затрагивает только собственную
сессию планирования пользователя. Это убирает ключи идемпотентности, конфликты переоценки и весь класс работы над
корректностью, которого требуют деньги, — и это честное следствие отсутствия бронируемых остатков, а не
достижение проектирования.

## 8. Errors are `application/problem+json`

RFC 9457. `OfferChangedProblem` расширяет его старой и новой ценой, потому что этому конкретному отказу нужны
данные, а не только сообщение.

## Известные пробелы

| Пробел | Ждёт |
|---|---|
| Аутентификация | OQ-H — вероятно, не нужна: возвращаться не к чему |
| Постраничность | Пока не нужна; продукт намеренно возвращает три Future, а не список |
| Ограничение частоты | Живых зависимостей только две (Ignav, Open-Meteo); вернуться, если одна из них укусит |
| Вебхуки | Поставщик отдаёт статус опросом; если это изменится, появится `04_api/webhook_contracts.md` |
| Семантика `persist_to_travel_dna` | OQ-G — сейчас выставлена флагом, чтобы клиент не угадывал молча |
