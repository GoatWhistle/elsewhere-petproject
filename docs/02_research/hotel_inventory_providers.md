# Складские остатки отелей — почему поставщика нет

Решение: [DEC-016](../00_project/decision_log.md).

Требование было: бесплатно, без шлюза одобрения, проверяемо сегодня. Каждый путь к реальным ценам отелей на даты
его проваливает.

| Путь | Данные | Почему отвергнут |
|---|---|---|
| Yandex Travel Partner API | отели, предложения, отзывы, заказы | партнёрская модерация; отзывы недоступны на лёгком пути |
| Travelpayouts / Hotellook | кэшированные цены отелей, статический каталог | живой поиск требует *«отдельного одобрения доступа»*; бронирования нет |
| RateHawk (Emerging Travel) | настоящие остатки, песочница с четвёртого квартала 2025 | договор с отделом продаж |
| Ostrovok B2B | настоящие остатки | договор |
| Bronevik | 80 тысяч объектов | заявка и NDA |
| Amadeus Self-Service | отели, предложения, тональность отзывов, перелёты, мгновенный бесплатный ключ | отвергнут: нероссийский |
| Сбор цен на даты со страниц | — | цены везде за XHR и защитой от ботов, см. ниже |

Проверенные детали и цитаты: [research_log](research_log.md).

## Что реально даёт сбор со страниц

- **101hotels.com** — микроразметка на стороне сервера: название, широта, долгота, адрес, изображение, рейтинг,
  `data-price-value`. Около 21 объекта на страницу каталога. **Каталог собирается чисто.**
  Но цены одинаковы для сентября и декабря в Сочи — завлекающее «от», а не котировка на даты.
  Перед сайтом стоит `server: QRATOR`.
- **ostrovok.ru** — поисковые пути запрещены в robots.txt; страницы объектов разрешены.
- **tvil.ru** — двухкилобайтная оболочка, всё рисуется на клиенте.

Итого: каталог да, цены на даты нет. Это тот же вывод, что был раньше сделан по Яндексу, теперь измеренный на
трёх сайтах.

## Что мы делаем вместо этого

Собираем каталог однажды; моделируем цену за ночь поверх реальных наблюдаемых ценовых уровней.
Полное соответствие — в [data_sources](../03_architecture/data_sources.md).

Партнёрские API остаются путём улучшения за тем же интерфейсом `Supply`
([DEC-005](../00_project/decision_log.md)): если настоящие бронируемые остатки когда-нибудь понадобятся,
меняется одна реализация адаптера и больше ничего.
