# Обзор проекта

## Что это за проект

Elsewhere — платформа планирования путешествий, где пользователь выбирает *версию своей будущей поездки*, а не
ищет отель в каталоге.

## Происхождение

Продуктовая идея берёт начало в [original_idea.md](original_idea.md). Это вход, а не источник правды —
источником правды является дерево `/docs`.

## Метод работы

1. Понять и усилить продукт.
2. Найти недостающие продуктовые и бизнесовые решения.
3. Задать владельцу продукта вопросы, которые существенно меняют систему.
4. Формализовать продуктовую и доменную модель.
5. Определить границы MVP.
6. Исследовать и выбрать внешних поставщиков данных.
7. Спроектировать архитектуру.
8. Проверить архитектуру на реальных пользовательских сценариях.
9. Вывести границы реализации и план поставки.
10. Реализовать.

Архитектура вырастает из продуктовых решений, никогда наоборот.
