# Ограничения

Ограничения — условия, которые система обязана уважать. Выбранные компромиссы и их причины находятся в
[журнале решений](decision_log.md).

## Технологический контур

Backend работает на Ruby, Rails и PostgreSQL/PostGIS. Границы реализованы пакетами Packwerk внутри модульного
монолита. Новая служба или инфраструктурная зависимость появляется только при доказанном требовании.

Frontend — веб-приложение на React и TypeScript. Мобильные клиенты в MVP не поддерживаются.

## Нет поставщика бронируемых отелей

Бесплатного открытого источника реальных остатков и цен проживания на даты для выбранного рынка нет. Следствия:

- каталог собирается один раз и хранится локально;
- сбор не происходит во время пользовательского запроса;
- защита от ботов не обходится;
- цена проживания строится на наблюдаемом базовом уровне и модельной сезонности;
- модельная цена всегда маркируется `modeled` и не выдаётся за котировку.

## Нет источника отзывов

Текстов отзывов и производной тональности нет. Forecast использует географию и климат, а review-only типы риска
остаются неоценёнными с явной причиной. Рейтинг объекта не считается заменой текста отзывов.

## У внешних данных есть условия

- основной API OpenStreetMap предназначен для редактирования; проект использует ограниченный импорт Overpass;
- Open-Meteo на бесплатном тарифе подходит для некоммерческого использования;
- Ignav и OpenRouteService требуют ключи для live-функций;
- ключи и пользовательские секреты не коммитятся.

Перед коммерческим запуском лицензии и тарифы поставщиков должны быть проверены заново.

## Честность важнее полноты

Система различает:

- наблюдаемый факт;
- производную метрику;
- вывод модели;
- модельную цену;
- неизвестность.

Отсутствующее измерение нельзя молча заменить нулём или нейтральным значением. Ошибка поставщика не должна
превращаться в выдуманное предложение. Один уверенный, но неподтверждённый риск разрушает доверие ко всему
Forecast.

## Нет транзакции

Elsewhere ничего не бронирует, не создаёт заказов и не принимает оплату. В продукте нет PCI-поверхности,
жизненного цикла заказа или гарантии доступности. Результат — план и оценка стоимости, по которым пользователь
действует самостоятельно.

## Ограниченный рынок и корпус

MVP работает с вылетом из России, рублями и семью курируемыми направлениями. Это не поиск по открытому миру.
Расширение рынка требует нового корпуса, проверки тарифного покрытия и пересмотра валютной модели.
