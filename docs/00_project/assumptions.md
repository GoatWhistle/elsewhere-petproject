# Допущения

Неподтверждённые убеждения. Допущение никогда не превращается в требование молча. Подтверждённое или
отвергнутое переезжает в [decision_log.md](decision_log.md) либо в продуктовый документ и удаляется отсюда.

---

| ID | Допущение | Почему мы его держим | Если оно неверно |
|---|---|---|---|
| A-001 | Пользователь путешествует ради отдыха и гибок в выборе направления | Продукт имеет смысл только для того, кто ещё не выбрал место | Тезис не применим вообще |
| A-002 | Один-два взрослых, без детей и требований доступности | В идее сказано «вдвоём» | Растут правила размещения, конфигурации номеров и сложность подбора |
| A-003 | Три Future — целевой размер выдачи | Из исходной идеи | Меняются и алгоритм разнообразия, и интерфейс |
| A-004 | Travel DNA живёт в рамках сессии; сохранение — после MVP | Самое малое, что доказывает тезис | Нужны идентификация, приватность, согласие |
| A-005 | Локальная мобильность может быть заявленным допущением, а не построенным маршрутом | Объём — логистика, а не программа ([DEC-018](decision_log.md)) | Нужна настоящая маршрутизация по транспорту |
| A-006 | Корпус — курируемый набор направлений, а не открытый мир | Делает географические доказательства и разнообразие по-настоящему хорошими, а демонстрацию независимой от внешнего мира | Поиск придётся строить под открытый мир с первого дня |
| A-007 | Фикстуры строятся из **реально захваченных ответов**, а не из выдуманных форм | Иначе утверждение о границе интерфейса — фикция | Граница адаптера перестаёт быть надёжной |
| A-008 | Модульного монолита на Rails и PostgreSQL достаточно | Ни одно требование пока не доказывает обратного | Пересматривать только при доказанной причине ([DEC-002](decision_log.md)) |
| A-009 | Используется внешний LLM API; модели у себя мы не держим | Бюджет времени | Меняются задержка, стоимость и обращение с данными |
| A-010 | Клиент только веб | Требования по мобильным не заявлены | Меняются API и проектирование взаимодействия |
| A-011 | Одна пользовательская роль; аккаунтов в MVP нет | Возвращаться не к чему — ни заказа, ни денег | Работа с идентификацией появляется раньше |
| A-012 | Наблюдаемых ценовых уровней из сбора каталога достаточно, чтобы откалибровать правдоподобную цену номера | Не проверено — самое крупное открытое допущение в плане данных | Единственное синтетическое число перестаёт убеждать, а вместе с ним и разговор о бюджете. См. OQ-A |
